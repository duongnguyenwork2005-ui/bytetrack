<h2 class="title">Sensor Setup</h2>
<div class="entry"><p>
This page provides additional information about the recording platform and sensor setup we have used to record this dataset. Our recording platform is a <a href="http://en.wikipedia.org/wiki/Volkswagen_Passat_%28B6%29" target="_blank">Volkswagen Passat B6</a>, which has been modified with actuators for the pedals (acceleration and brake) and the steering wheel. The data is recorded using an eight core i7 computer equipped with a RAID system, running Ubuntu Linux and a <a href="http://www.kogmo-rtdb.de/" target="_blank">real-time database</a>. We use the following sensors:<br>
</p>
<ul>
<li>1 Inertial Navigation System (GPS/IMU): <a href="http://www.oxts.com/default.asp?pageRef=21" target="_blank">OXTS RT 3003</a></li>
<li>1 Laserscanner: <a href="http://velodynelidar.com/lidar/hdlproducts/hdl64e.aspx" target="_blank">Velodyne HDL-64E</a></li>
<li>2 Grayscale cameras, 1.4 Megapixels: <a href="http://www.ptgrey.com/products/flea2/flea2_firewire_camera.asp" target="_blank">Point Grey Flea 2 (FL2-14S3M-C)</a></li>
<li>2 Color cameras, 1.4 Megapixels: <a href="http://www.ptgrey.com/products/flea2/flea2_firewire_camera.asp" target="_blank">Point Grey Flea 2 (FL2-14S3C-C)</a></li>
<li>4 Varifocal lenses, 4-8 mm: <a href="http://www.edmundoptics.com/imaging/imaging-lenses/zoom-lenses/varifocal-imaging-lenses/1620" target="_blank">Edmund Optics NT59-917</a></li>
</ul>
<p>
The laser scanner spins at 10 frames per second, capturing approximately 100k points per cycle. The vertical resolution of the laser scanner is 64. The cameras are mounted approximately level with the ground plane. The camera images are cropped to a size of 1382 x 512 pixels using <a href="http://damien.douxchamps.net/ieee1394/libdc1394/" target="_blank">libdc's</a> format 7 mode. After rectification, the images get slightly smaller. The cameras are triggered at 10 frames per second by the laser scanner (when facing forward) with shutter time adjusted dynamically (maximum shutter time: 2 ms). Our sensor setup with respect to the vehicle is illustrated in the following figure. Note that more information on calibration parameters is given in the calibration files and the development kit (see <a href="raw_data.php">raw data</a> section).<br>
</p>
